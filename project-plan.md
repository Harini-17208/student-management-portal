# Student Management Portal — Agile Scrum Plan

## 1. Project Objective
To develop a static Student Management Portal using HTML5 and CSS3. The website contains five pages: Home, About, Student Registration, Courses, and Contact.

## 2. Product Backlog

| Priority | User Story | Priority Level |
|---|---|---|
| 1 | As a visitor, I want to view the Home page. | High |
| 2 | As a visitor, I want to learn about the portal. | High |
| 3 | As a student, I want to access a registration form. | High |
| 4 | As a student, I want to view available courses. | Medium |
| 5 | As a visitor, I want to find contact information. | Medium |
| 6 | As a user, I want to navigate between pages. | High |
| 7 | As a user, I want a consistent website design. | Medium |

## 3. Sprint-1 Plan

**Duration:** 1 week

**Sprint Goal:** Develop and test the basic Student Management Portal.

### Sprint Backlog
1. Create a GitHub repository.
2. Develop the Home and About pages.
3. Create the Student Registration page.
4. Develop the Courses and Contact pages.
5. Create and link the CSS stylesheet.
6. Test navigation and website appearance.
7. Commit the project files to GitHub.

## 4. Scrum Roles
- **Product Owner:** Defines and prioritizes requirements.
- **Scrum Master:** Helps ensure Scrum practices are followed.
- **Developer:** Develops and tests the website.

For an individual project, the student may perform all three roles.

## 5. Definition of Done
- All five HTML pages are created.
- Navigation links work correctly.
- CSS is linked to all pages.
- The website is tested in a browser.
- Project files and documentation are committed to GitHub.

## 6. Technologies Used
HTML5, CSS3, Git, GitHub, and Agile Scrum.
